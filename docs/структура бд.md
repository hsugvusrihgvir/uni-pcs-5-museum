# Структура базы данных

## Таблицы

### `booking`

| Поле | Тип | Ограничения |
|---|---|---|
| `id` | `BIGINT` | `PRIMARY KEY`, `GENERATED ALWAYS AS IDENTITY` |
| `id_visitor` | `BIGINT` | `NOT NULL`, `FOREIGN KEY` → `visitor(id)`, `ON DELETE CASCADE` |
| `id_exhibition` | `BIGINT` | `NOT NULL`, `FOREIGN KEY` → `exhibitions(id)`, `ON DELETE CASCADE` |
| `visit_date` | `DATE` | `NOT NULL` |
| `status` | `booking_status` | `NOT NULL` |
| `price` | `DOUBLE PRECISION` | |

### `artworks`

| Поле | Тип | Ограничения |
|---|---|---|
| `id` | `BIGINT` | `PRIMARY KEY`, `GENERATED ALWAYS AS IDENTITY` |
| `title` | `VARCHAR(255)` | `NOT NULL` |
| `type` | `artwork_type` | `NOT NULL` |
| `description` | `TEXT` | |
| `year` | `INTEGER` | `CHECK (year IS NULL OR year BETWEEN 1 AND 2100)` |
| `width_cm` | `NUMERIC(10, 2)` | `CHECK (width_cm IS NULL OR width_cm > 0)` |
| `height_cm` | `NUMERIC(10, 2)` | `CHECK (height_cm IS NULL OR height_cm > 0)` |
| `depth_cm` | `NUMERIC(10, 2)` | `CHECK (depth_cm IS NULL OR depth_cm > 0)` |
| `status` | `artwork_status` | `NOT NULL` |

### `exhibitions`

| Поле | Тип | Ограничения |
|---|---|---|
| `id` | `BIGINT` | `PRIMARY KEY`, `GENERATED ALWAYS AS IDENTITY` |
| `title` | `VARCHAR(255)` | `NOT NULL` |
| `description` | `TEXT` | |
| `photo_url` | `TEXT` | |
| `start_date` | `DATE` | `NOT NULL` |
| `end_date` | `DATE` | `NOT NULL`, `CHECK (end_date >= start_date)` |
| `hall_number` | `INTEGER` | `NOT NULL`, `CHECK (hall_number > 0)` |

### `visitor`

| Поле | Тип | Ограничения |
|---|---|---|
| `id` | `BIGINT` | `PRIMARY KEY`, `GENERATED ALWAYS AS IDENTITY` |
| `name` | `VARCHAR(255)` | `NOT NULL` |
| `last_name` | `VARCHAR(255)` | `NOT NULL` |
| `patronymic` | `VARCHAR(255)` | |
| `birth_date` | `DATE` | |
| `email` | `VARCHAR(255)` | `NOT NULL`, `UNIQUE` |
| `password_hash` | `VARCHAR(255)` | `NOT NULL` |

### `authors`

| Поле | Тип | Ограничения |
|---|---|---|
| `id` | `BIGINT` | `PRIMARY KEY`, `GENERATED ALWAYS AS IDENTITY` |
| `name` | `VARCHAR(255)` | `NOT NULL` |
| `last_name` | `VARCHAR(255)` | `NOT NULL` |
| `patronymic` | `VARCHAR(255)` | |
| `country` | `VARCHAR(100)` | |
| `description` | `TEXT` | |
| `photo_url` | `TEXT` | |
| `birth_date` | `DATE` | |
| `death_date` | `DATE` | `CHECK (death_date IS NULL OR birth_date IS NULL OR death_date >= birth_date)` |

### `materials`

| Поле | Тип | Ограничения |
|---|---|---|
| `id` | `BIGINT` | `PRIMARY KEY`, `GENERATED ALWAYS AS IDENTITY` |
| `name` | `VARCHAR(255)` | `NOT NULL`, `UNIQUE` |

### `employee`

| Поле | Тип | Ограничения |
|---|---|---|
| `id` | `BIGINT` | `PRIMARY KEY`, `GENERATED ALWAYS AS IDENTITY` |
| `name` | `VARCHAR(255)` | `NOT NULL` |
| `last_name` | `VARCHAR(255)` | `NOT NULL` |
| `patronymic` | `VARCHAR(255)` | |
| `birth_date` | `DATE` | |
| `position` | `employee_position` | `NOT NULL` |
| `email` | `VARCHAR(255)` | `NOT NULL`, `UNIQUE` |
| `password_hash` | `VARCHAR(255)` | `NOT NULL` |
| `phone` | `VARCHAR(30)` | `UNIQUE` |

### `photos`

| Поле | Тип | Ограничения |
|---|---|---|
| `id` | `BIGINT` | `PRIMARY KEY`, `GENERATED ALWAYS AS IDENTITY` |
| `id_artwork` | `BIGINT` | `NOT NULL`, `FOREIGN KEY` → `artworks(id)`, `ON DELETE CASCADE`, `UNIQUE WHERE is_main = TRUE` |
| `photo_url` | `TEXT` | `NOT NULL` |
| `is_main` | `BOOLEAN` | `NOT NULL`, `DEFAULT FALSE` |

### `artwork_authors`

| Поле | Тип | Ограничения |
|---|---|---|
| `id_author` | `BIGINT` | `NOT NULL`, `PRIMARY KEY (id_author, id_artwork)`, `FOREIGN KEY` → `authors(id)`, `ON DELETE RESTRICT` |
| `id_artwork` | `BIGINT` | `NOT NULL`, `FOREIGN KEY` → `artworks(id)`, `ON DELETE CASCADE` |

### `artwork_materials`

| Поле | Тип | Ограничения |
|---|---|---|
| `id_artwork` | `BIGINT` | `NOT NULL`, `PRIMARY KEY (id_artwork, id_material)`, `FOREIGN KEY` → `artworks(id)`, `ON DELETE CASCADE` |
| `id_material` | `BIGINT` | `NOT NULL`, `FOREIGN KEY` → `materials(id)`, `ON DELETE RESTRICT` |

### `artwork_exhibitions`

| Поле | Тип | Ограничения |
|---|---|---|
| `id_artwork` | `BIGINT` | `NOT NULL`, `PRIMARY KEY (id_artwork, id_exhibition)`, `FOREIGN KEY` → `artworks(id)`, `ON DELETE CASCADE` |
| `id_exhibition` | `BIGINT` | `NOT NULL`, `FOREIGN KEY` → `exhibitions(id)`, `ON DELETE CASCADE` |

### `employee_exhibitions`

| Поле | Тип | Ограничения |
|---|---|---|
| `id_exhibition` | `BIGINT` | `NOT NULL`, `PRIMARY KEY (id_exhibition, id_employee)`, `FOREIGN KEY` → `exhibitions(id)`, `ON DELETE CASCADE` |
| `id_employee` | `BIGINT` | `NOT NULL`, `FOREIGN KEY` → `employee(id)`, `ON DELETE CASCADE` |
