# Подготовка проекта к запуску

Перед первым запуском проекта или тестов нужно один раз настроить локальную PostgreSQL.

1. Установить и запустить PostgreSQL.
2. Клонировать репозиторий и открыть проект как Maven-проект.
3. Использовать JDK, указанную в `pom.xml`, и выполнить Maven Reload, чтобы зависимости загрузились.
4. Создать локальную БД:

```sql
CREATE DATABASE museum_db;
```

5. Подключиться именно к `museum_db` и выполнить по порядку:

```text
database/schema.sql
database/data.sql
```

`schema.sql` создаёт структуру БД, а `data.sql` заполняет её тестовыми данными.

> `data.sql` очищает тестовые таблицы и сбрасывает ID.
